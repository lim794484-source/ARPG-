## 🚀 1. 从哪里启动

1. 在 Unity Hub／团结 Hub 中添加项目目录 `D:\my_arpg-master`。
2. 优先使用工程记录的编辑器：**团结引擎 1.8.5，编辑器版本 2022.3.62t7**。README 中的 Unity 2022.3.62f3c1 是旧说明，不是当前 `ProjectVersion.txt` 的值。
3. 等待导入和编译完成，打开 `Assets/Scenes/InitialScene.unity`，点击编辑器顶部 ▶ Play。
4. 等待标题菜单出现，第一次游玩选择 **Start／开始**。先不要点 Continue，首次运行可能没有可继续的系统存档。
5. 点击一下 **Game** 画面，让键盘输入进入游戏。

> [!TIP]
> 完整流程从 `InitialScene` 启动：它加载 `PersistentScene`，再进入标题／游戏场景。直接运行 `Scene1`、`Scene2` 或 `TestScene` 不能作为完整体验入口。

如果已有独立运行包，直接启动游戏程序，随后从第 4 步开始。需要一轮全新体验时，退出程序再启动，或在编辑器停止 Play 后重新运行；**同一运行期间“返回标题 → Start”不保证清空所有运行状态**。

## 🎮 2. 操作速查

| 操作 | 当前按键／方式 | 使用条件与说明 |
| --- | --- | --- |
| 移动 | WASD 或方向键 | 靠近掉落物即可自动拾取 |
| 切换剑／弓 | Q | 初始为剑；切换有约 0.3 秒间隔 |
| 攻击 | J | 剑模式挥砍，弓模式射箭；**当前 K 没有攻击绑定** |
| 弓箭定向 | 按住方向键或 WASD，再按 J | 支持上下、左右、斜向；不按方向时按角色左右朝向射出，不随鼠标瞄准 |
| 属性面板 | 数字 1 | 查看攻击、速度等数值 |
| 技能面板 | 数字 2 | 左键可用技能槽升级，需技能点 |
| 背包 | B | 与底部物品栏一起存放物品 |
| 商店 | F | 必须靠近商人 |
| 对话 | T | 必须靠近 NPC、进入其交互范围 |
| 推进对话／选项 | 鼠标左键 | 读到结尾并让对话自然结束，才可靠记录已交谈 |
| 任务板 | C | 必须靠近任务板；不是随地可开的全局任务日志 |
| 关闭顶层面板 | Esc 或面板 X | Esc 先关闭最上层窗口；没有窗口时才打开暂停菜单 |
| 暂停菜单 | 无其他面板时按 Esc | 可返回标题、打开存读档、退出；再按 Esc 关闭 |
| 原有简版指南 | 标题菜单 Guide／G | 标题场景已接入，用系统程序打开 GameGuide.txt；其中部分说明过时 |
| 使用物品 | 商店关闭时左键物品槽 | 每次消耗 1 个 |
| 出售物品 | 商店打开时左键物品槽 | 每次卖 1 个，建议先切到对应商品分类 |
| 丢弃物品 | 右键物品槽 | 每次丢 1 个；离开掉落位置后再靠近才能重新拾取 |
| 移动窗口 | 拖动顶部标题栏 | 多数面板支持；拖动或唤起可将窗口提到前面 |

> [!WARNING]
> 面板快捷键主要用于打开／置前，不保证重复按同一键关闭。关闭请用 **X** 或 **Esc**。普通背包、属性、商店等面板不会统一暂停战斗，请先离开敌人再操作。

## 🧩 4. 推荐完整路线

### ① 熟悉界面，增加一点生存能力

1. 从出生点移动几步，测试 WASD 与方向键。
2. 按 1 查看初始属性：攻击 2、速度 5、生命 2／2，初始等级 0。
3. 按 2，找到已可用的“生命强化”槽，花初始的 **1 点技能点**升一级。预期最大生命和当前生命各加 1。
4. 打开 B 背包；尝试将背包和属性面板拖开，再按 1 把属性面板置前。
5. 连按 Esc，观察窗口逐层关闭，最后才出现暂停菜单。再次 Esc 回到游戏。
6. 点击左下角集成菜单，试着打开属性、技能、背包；商店、任务和对话仍需要靠近对应对象。

### ② 接任务，先看条件不满足的对话

1. 走到主任务板 `(1.76, -2.23)` 附近，按 C。
2. 点选“采集与拜访”，接受任务。
3. 点选“购物之旅”，接受任务。要体验任务放弃流程，可以先对这一项点“拒绝／放弃”（Decline），再接受回来。
4. 关闭任务面板。先去问候型紫袍鲍勃附近，按 T：尚未与黄衣鲍勃交谈时，应提示去木桥附近找他。
5. 继续左键，直到对话自行关闭。**不要用 T、Esc 或走远来代替读完**，强制结束不会执行正常的对话记录流程。
6. 去收集型紫袍鲍勃附近，按 T。物品不足时，应看到“采集 5 个蘑菇并购买 3 份生肉”的要求；同样完整读完。

> [!IMPORTANT]
> 这里有两套条件：任务板只要求 **3 个蘑菇**；收集型 NPC 的完整剧情要求 **5 个蘑菇＋3 份生肉**。为了看全内容，请按后者准备。

### ③ 采集、捡钱、购物

1. 在蘑菇区走过至少 3 个红蘑菇拾取物，正常可获得至少 **6 个蘑菇**。检查底部物品栏与 B 背包中的数量、堆叠和溢出到下一格的效果。
2. 到 `(13.11, -6.88)` 捡 10 金币；附近有敌人，先保持距离，需要战斗时可用 Q 切弓、方向＋J 远程攻击。
3. 到较便宜商人附近按 F，把鼠标移到生肉／蘑菇上，查看名称、描述、属性和持续时间提示。
4. 买 **3 份生肉**，合计 9 金币，捡到的 10 金币足够。确认物品增加、金币减少。
5. 依次点商店的物品、武器、护甲分类，再切回物品分类。
6. 靠近另一位商人按 F，比较蘑菇价格，并观察商人肖像与货架随当前商人变化。走出商人范围，商店应关闭。

> [!CAUTION]
> 此时请保留至少 **5 个蘑菇＋3 份生肉**。使用、出售会减少系统用于条件判断的数量，过早消耗可能使任务或剧情条件失效。

### ④ 看全两组对话分支

1. 沿地图道路向下寻找木桥附近的黄衣鲍勃，按 T 并左键完整读到结束。
2. 回到问候型紫袍鲍勃。现在应进入问候对话，而不再提示寻找黄衣鲍勃。
3. 推进至选项，选“了解更多”，读完；重新交谈，再选“不感兴趣”，读完。
4. 带着至少 5 个蘑菇和 3 份生肉去收集型紫袍鲍勃，应出现谈论蘑菇和索取蘑菇的对话。
5. **先选“拒绝”**，读完“真遗憾……”；重新交谈，**再选“同意”**，完整读到结束。
6. 再次与收集型鲍勃交谈，体验一次性剧情完成后的简短默认问候。

> [!TIP]
> 请按“**拒绝 → 再次交谈 → 同意**”的顺序选择。“同意”会记录剧情已完成，这样才能在一轮中看全两个分支。

对话里提到“几天后送汤”目前只是台词，没有等待数天领取汤的玩法，也没有在此处实际扣除物品的交付逻辑。

### ⑤ 提交两个正式任务

回主任务板，按 C，逐项选中任务查看目标。

| 任务 | 实际完成条件 | 奖励 |
| --- | --- | --- |
| 采集与拜访 | 蘑菇记录至少 3；与紫袍鲍勃完成一次交谈 | 10 金币、10 经验、2 木材 |
| 购物之旅 | 生肉记录至少 3 | 10 金币 |

1. 查看目标的数量或勾选状态；若尚未刷新，切换任务条目或关闭后重新打开。
2. 点“完成／Complete”领取奖励；只是达到条件不会自动发奖。
3. 检查金币、木材、经验／等级。初始升级门槛为 10 经验，采集任务的 10 经验足以触发首次升级（若已升级则按当前状态计算）。
4. 两项任务完成后关闭重开，观察该任务板全部完成后的提示和已完成条目的变暗状态。
5. 到 `(8.46, -5.29)` 查看空任务板，再到 `(13.70, -1.53)` 查看“默认任务”。它没有目标也没有奖励，是可接受／完成的占位任务。

“购物之旅”的描述提到和老板交谈，但资源中只配置了生肉数量目标，没有另一个老板对话目标。“采集与拜访”的描述提到送蘑菇，当前提交逻辑只检查条件并发奖励，不扣掉这些蘑菇。

任务进度使用物品记录：拾取、购买增加，使用、出售减少；丢弃的记录处理又不完全一致。因此不要把它理解成永不减少的累计采集成就，也不要用反复丢捡代替正常完成。

### ⑥ 物品使用、出售、丢弃与背包

剧情和任务完成后再做本节，避免消耗前置物品。

1. **使用蘑菇：** 关闭商店，按 1 打开属性面板，再左键蘑菇槽。回复 2 生命，最大生命临时加 2、速度临时加 2，临时加成持续约 2 秒。
2. **使用生肉：** 左键生肉槽，回复 2 生命，速度临时加 1、攻击临时加 2，约 2 秒后还原。可先受一点伤再尝试回复。
3. **出售：** 靠近商人打开 F，切回物品分类，再左键自己的蘑菇或生肉槽。每次出售 1 个，金币按当前商店价格增加。
4. **丢弃和捡回：** 关闭商店，右键剩余蘑菇，确认地面出现 1 个。走离它，再回来拾取。仅站在原地不会立即捡回。
5. **堆叠：** 蘑菇每格 5 个、生肉每格 3 个、木材每格 10 个；检查超过上限后是否进入别的空槽。
6. **可选容量体验：** 采集更多蘑菇或购买物品填充空格，观察背包不足时无法购买、拾取余量留在地面的情况。无需为填满背包反复刷资源才算体验完成。

金币直接计入货币，经验直接进入经验条。木材目前没有建造用途，左键使用只会消耗它，不会建城堡。地上由玩家丢出的物品不会在切图、重载、Retry 后重新生成，想保留就先捡回。

### ⑦ 战斗、升级与技能树

1. 找一只火把哥布林，先观察靠近后追逐、绕障碍移动，拉远后的状态变化。
2. 在剑模式朝向敌人，按 J 近战，观察敌人受击、击退；每次攻击会短暂停住，等待动作与冷却完成后再按。
3. 按 Q 切弓，按住方向＋J 射箭，分别试水平、向上／下、斜向射击。
4. 让敌人命中一次，观察生命减少和击退。初始生命很低，不要同时吸引多只。
5. 击败敌人，观察经验条；哥布林预制体每只提供 2 经验。没有配置“每次击杀必掉金币／装备”的流程。
6. 按 2 使用新技能点。体验“剑刃斩击”一次升级（上限 1），以及“生命强化”升级（每槽上限 5）。升级剑刃斩击时先处于剑模式，避免该技能与武器切换状态互相影响。
7. 将一个生命强化前置槽升到 5／5，观察后续槽由灰色“未解锁”变为可用。多前置槽的节点必须等所有前置都满级。

技能树看起来节点很多，当前效果类型只有“剑刃斩击”和“生命强化”；多个节点复用生命强化。初始剑模式已经能攻击，剑刃斩击节点没有新增独立攻击按键。

> [!WARNING]
> `expMultiplier` 当前为 0。首次升级后，下一次升级门槛会变为 0，继续获得经验时会异常容易升级。这不是正常成长曲线；体验机制即可，无需刷满所有重复技能槽。

### ⑧ 第二张地图、地形与重复挑战

1. 先捡回想保留的丢弃物，再走到 Scene1 木桥出口 `(8.49, -21.09)`。
2. 观察淡出／淡入和场景切换。Scene2 默认入口约 `(10.5, 8)`。
3. 向地图内部探索，尝试楼梯与高低层通路，观察角色与地形的遮挡；岩壁不能直接穿过，应走楼梯。
4. Scene2 配置了 **10 只同类哥布林**，适合继续体验战斗与技能点获取。没有在此发现独立 Boss 或新的敌人类型。
5. Scene2 同样有蘑菇、10 金币、三块任务板，并有一位问候型紫袍 NPC（初始约 `(3.76, -5.52)`）。任务板对应坐标与 Scene1 表格相同；没有场景商人实例。
6. 本次运行中已完成的同一任务会共享完成状态，不是每块板都能重复领奖。
7. 回到 Scene2 出口 `(10.53, 8.8)` 可返回 Scene1。进入 Scene2 后先向内走，避免一直停在返回触发区。
8. 重新进入地图时，敌人没有持久化死亡记录，会随场景重新创建；可用来补充技能体验所需经验。场景原生采集物则有已拾取记录，不能假设切图就全部刷新。

## 💾 5. 存档、读档、继续与死亡：放在最后体验

### 📁 手动存档与读档

1. 在安全地点等食物临时效果消退，再依次按 Esc 关闭其他窗口，打开暂停菜单中的存读档入口。
2. 在一行点击“保存／Save”，确认该行出现存档信息／文件路径。保存以时间戳生成文件，不要把它理解成固定槽位必然原地覆盖。
3. 关闭面板和暂停菜单，走到另一个明显位置。
4. 再打开存读档，找到刚刚那份有信息的存档并点“读取／Load”，观察场景和位置恢复。
5. 回标题后打开存读档界面，原“保存”按钮变为“删除”。若要体验删除，只删除你专门创建的测试档，并保留一份需要的记录。

### ▶️ Continue 与自动系统档

1. 完成一次场景切换，或从游戏返回标题，会触发系统存档流程。
2. 在标题点 Continue／继续，检查能否回到最近可加载的系统档场景。
3. **Continue 读取系统档，不等于读取最新手动档。** 想回到某次手动保存，去存读档列表选择对应文件。

### ☠️ 死亡与 Retry

1. 在完成前面的剧情、任务和交易体验之后，保留一份测试存档。
2. 让敌人连续命中直至生命归零，观察 GameOver 界面。
3. 点击 Retry／重试，观察当前地图重新加载、角色返回该地图的重试出生点；死亡生命会恢复至最大值。
4. Retry 是重新加载当前地图，并非完整恢复某份手动存档，也不会重建玩家丢弃在地上的物品。

## 🧰 6. 没反应时，按这张表处理

| 现象 | 优先检查 |
| --- | --- |
| 按键没有响应 | 点击 Game 画面；确认不是暂停状态，也不是只单独启动了 Scene1 |
| K 不能攻击 | 当前两种攻击都绑定 J；按 Q 选择剑或弓 |
| 箭没朝鼠标位置飞 | 使用方向键／WASD＋J；鼠标不是瞄准输入 |
| C、F、T 不开界面 | 分别靠近任务板、商人、NPC；关闭暂停菜单，稍等其进入交互状态再按 |
| 重复快捷键没有关闭面板 | 当前主要是打开／置前逻辑，用 X 或 Esc 关闭 |
| Esc 没显示暂停 | 它先关最上层窗口；继续按直到普通窗口都关完 |
| 对话完了任务还没计数 | 别用 T／Esc／走远强制结束；左键推进到自然结束，再回任务板刷新 |
| 鲍勃一直要你找黄衣鲍勃 | 去木桥附近完成黄衣鲍勃全部台词，再回来 |
| 鲍勃一直要物品 | 确保至少 5 蘑菇＋3 生肉，并且没有提前吃掉或卖掉 |
| 已做完但 Complete 无效 | 再选择该任务或关闭重开以刷新；当前进度显示与检查可能晚一次刷新 |
| 买不了生肉／蘑菇 | 检查金币、背包空间；商品每次购买数量是 1 |
| 打开商店后吃东西反而加钱 | 商店打开时左键槽位是出售；先关闭商店 |
| 木材卖不掉 | 商店出售逻辑按商品槽匹配，当前货架没有木材；未实现任意物品回收 |
| 弓商品买不了 | 弓资源堆叠上限为 0，背包没有可放入容量；用 Q 直接体验弓战斗 |
| 地上丢的东西捡不回 | 先离开再走回；若已经切图或 Retry，该丢弃物不保证存在 |
| 返回标题后 Start 没完全重置 | 完全退出重开／停止再运行 Play；当前没有完整的新游戏状态重置 |
| 标题 Continue 无反应 | 可能尚无有效系统档；先 Start 游玩并切图／返回标题，或手动选择已有有效存档 |
| 启动停住／黑屏 | 从 InitialScene 重试，查看 Console 首条红色错误；优先核对编辑器版本、编译、Addressables 场景引用。此类属于工程运行问题，不能靠游戏按键解决 |

## 🚧 7. 哪些是占位或尚不能完整体验的功能

- **木材建造、等待获得汤、位置访问任务：** 有文案或框架痕迹，但未接入完整玩家流程。
- **手柄：** 输入文件声明了 Gamepad 方案，却没有对应动作绑定，本文按键鼠路线执行。
- **触屏：** 有移动摇杆代码，但不能据此保证触屏能完成全部攻击、分支、右键丢弃等操作；完整体验优先用电脑键鼠。
- **TestScene：** 调试场景，不是正式路线中的隐藏关卡。
